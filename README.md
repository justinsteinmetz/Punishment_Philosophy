# Punishment & the State
### Interactive discussion tools for Year 10 Politics & Society

Three standalone HTML files. Deploy any or all to GitHub Pages — no build step, no dependencies, no server required.

---

## Files

### `punishment-philosophy.html`
**Student-facing reference tool**

The full lesson in scrollable format. Students can work through it independently, on their own device, before or after class. Designed for the DSP English Hub.

- Parchment palette, editorial typography — feels like a seminar handout, not a worksheet
- Four theory cards (Retribution / Deterrence / Rehabilitation / Incapacitation), each expandable with a deeper explanation and two targeted discussion prompts
- Theory footer: *"Most real systems use all four — the real question is when each one should win."*
- US vs Norway evidence comparison
- Six scenarios in sequence: Shoplifter → US/Norway → Recidivist → Extremist → State's Limits → Billionaire → Big Question
- Ends with a final unscaffolded question: *What is punishment for?*

---

### `punishment-philosophy-projection.html`
**Full lesson — teacher-led projection version**

The complete deck for a 40–50 minute discussion lesson. Dark theme, full-screen, keyboard-driven. Teacher controls every reveal.

- 11 slides
- Space / → advances; ← steps back (or hides last prompt if prompts are showing)
- Discussion prompts reveal one at a time — you decide when the room is ready
- Theory cards auto-animate in on entry; footer line fades in last
- Fullscreen button top-right; gold progress bar along the bottom

**Slide sequence:**
1. Title
2. Four theories
3. Shoplifter
4. US vs Norway
5. Recidivist
6. Extremist
7. State's limits
8. Billionaire
9. Big question
10. Final: *What is punishment for?*

## Discussion prompt colour coding

All three files use the same system:

| Colour | Function |
|---|---|
| Blue | Opening / analytical — "which theory applies here?" |
| Amber | Complicating — introduces a wrinkle or counter-case |
| Red | Destabilising — attacks the premise or forces a harder position |

Reveal prompts in order. The red prompt is usually the one that breaks open the discussion.

## Deployment

Drop any file into your GitHub Pages repo. No configuration needed.

```
justinsteinmetz.github.io/punishment-philosophy.html
justinsteinmetz.github.io/punishment-philosophy-projection.html
justinsteinmetz.github.io/punishment-philosophy-20min.html
```

Both projection files require an internet connection for Google Fonts (Playfair Display + Source Serif 4). The layout degrades gracefully to Georgia if fonts fail to load.
